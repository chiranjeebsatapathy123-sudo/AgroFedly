Roles & Permissions

{% trans "Define what users can see and do." %}

Super Administrator

System Role

Full, unrestricted access to the entire AgroFedly network. Can manage organizations, billing, and global settings.

Key Permissions:
  • Global Settings Management
  • Organization Onboarding
  • Audit Log Access

Organization Admin

System Role

Manages a single organization (e.g., Farm or Kitchen). Can add users within their organization and assign workspaces.

Key Permissions:
  • User Management (Org level)
  • Workspace Configuration
  • Local Data Export

Logistics Driver

Custom Role

Restricted access. Can only view assigned routes, update delivery status, and submit verification photos.

Key Permissions:
  • View Assigned Routes
  • Update Transfer Status
  • Upload POD (Proof of Delivery)
